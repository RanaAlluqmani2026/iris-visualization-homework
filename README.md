# Iris Data Visualization

This project was created for DATS 6401: Visualization of Complex Data.

## Research Question

**How does average petal length differ among Iris species?**

## Project Overview

This Streamlit application uses the Iris dataset to explore the same research question through three different visual encodings:

1. **Bar length** — compares average petal length using bars with a common baseline.
2. **Position** — represents average petal length through the vertical position of points on a shared scale.
3. **Circle size** — represents average petal length using the area of circles.

The goal is to demonstrate how different visual channels can affect the accuracy and ease of interpreting the same underlying data.

The application also discusses perceptual accuracy and visual principles including similarity, proximity, and preattentive size.
